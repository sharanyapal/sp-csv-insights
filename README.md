# CSV Insights

Upload CSV data, preview the schema, and generate a simple category aggregation chart.

**Live application:** https://sp-csv-insights.vercel.app  
**Technology:** HTML, CSS, JavaScript  
**Visual direction:** Editorial data magazine  
**Source:** https://github.com/sharanyapal/sp-csv-insights

## Implemented functionality

- Import local CSV files
- Schema preview and aggregation
- Data charts based on selected columns

## Run locally

```bash
python -m http.server 8000
# Open http://localhost:8000
```

No build step or account required.

## Project structure

- `index.html` — semantic interactive application page
- `style.css` — independent responsive art direction and components
- `app.js` — application logic and input handling
- `app-base.js` — local browser utilities

## Safety and scope

A working portfolio-scale app, not a production security service. Local-only browser computation unless otherwise explained. No credentials are included.
